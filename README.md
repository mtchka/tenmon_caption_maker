# tenmon_caption_maker
天体写真のキャプションをcsvファイルの情報から作成するプログラムです。
筑波大学天文研究会の雙峰祭における写真展でのキャプション制作用です。（物好きな方がいればご自由に応用してもらって構いません。）

最終的には各キャプションを1スライドとしたPowerPointファイルが完成します。
